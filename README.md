# Cloud Journey
A hands on journey from cloud fundamentals to Cloud AI Engineering.

## Goal
Build practical skills in cloud computing, AWS, Linux, networking, Python, DevOps and AI/ ML through structured learning, hands-on labs and real-world projects.

## Learning path
| Phase  | Focus Area              | What You'll Learn                                                                    | Outcome                                              |
| ------ | ----------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| **01** |  Cloud Fundamentals   | Cloud concepts, virtualization, servers, storage, networking, scalability            | Understand how cloud computing works                 |
| **02** |  Linux + Networking   | Linux filesystem, CLI, permissions, processes, SSH, TCP/IP, DNS, HTTP/HTTPS          | Work confidently with Linux servers                  |
| **03** |  AWS                  | EC2, S3, IAM, VPC, databases, monitoring, security, serverless                       | Build and manage AWS infrastructure                  |
| **04** |  Python               | Python fundamentals, scripting, APIs, automation, error handling                     | Automate cloud tasks and build applications          |
| **05** |  DevOps + Containers  | Docker, Git, CI/CD, deployment, infrastructure concepts                              | Build and deploy applications reliably               |
| **06** |  AI/ML Fundamentals   | ML concepts, model training vs inference, LLMs, embeddings, APIs                     | Understand the AI layer without going research-heavy |
| **07** |  Cloud AI Engineering | AI applications on AWS, RAG, vector databases, AI services, inference, AI deployment | Build cloud-based AI solutions                       |
| **08** |  Real-World Projects  | End-to-end AWS + Python + Docker + AI projects                                       | Build a job-ready Cloud AI portfolio                 |
